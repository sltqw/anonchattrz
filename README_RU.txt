АНОНИМНЫЙ ЧАТ — СЕРВЕРНАЯ ВЕРСИЯ

В комплекте:
- public/index.html — обновлённый сайт (медиафайлы тоже положите в public/);
- server.js — Node.js + Socket.IO сервер;
- package.json — зависимости;
- data/chat.sqlite — база данных создаётся автоматически при первом запуске.

ЛОКАЛЬНЫЙ ЗАПУСК
1. Установите Node.js 20 или новее.
2. Откройте терминал в папке проекта.
3. Выполните: npm install
4. Выполните: npm start
5. Откройте http://localhost:3000

ПУБЛИКАЦИЯ В ИНТЕРНЕТЕ
1. Загрузите все файлы проекта в GitHub.
2. Создайте Node.js сервис на Railway (или другом хостинге, который поддерживает WebSocket).
3. Укажите команду запуска: npm start
4. Добавьте постоянный Volume и установите переменную DATA_DIR=/data.
5. Подключите Volume к /data, чтобы SQLite база не удалялась при перезапуске/деплое.
6. Сгенерируйте публичный домен HTTPS.

ВАЖНО
- Это анонимный прототип без регистрации по паролю. ID профиля хранится в браузере; очистка данных браузера создаст новый профиль.
- Поскольку нет подтверждённой учётной записи, пользователь технически может подменить свой ID. Не используйте для секретных или чувствительных переписок.
- Личные сообщения сохраняются на сервере и доступны отправителю/получателю через интерфейс. Администратор сервера технически имеет доступ к файлам базы данных.
- Для серьёзного публичного сервиса нужно добавить регистрацию, проверку личности/сессий, жалобы/блокировки, антиспам и резервные копии.
- Для картинок профиля действует лимит размера Socket.IO около 1 МБ. Очень большие изображения могут не синхронизироваться.
- Сохраните рядом с index.html исходные медиафайлы сайта: r.gif, e.gif, t.gif, q.gif, s.gif, tv.jpg, ural.mpeg, uide.mpeg, tv.mpeg, lazer.mpeg, phatom.mpeg (если они используются) в папку public/. Этих файлов не было среди переданных материалов, поэтому они в архив не включены.
